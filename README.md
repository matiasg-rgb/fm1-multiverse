# Open Instruments — FM-1 Multiverse collection v0.2.0

25 projects in the portfolio. This release provides 21 source-backed browser editions and 20 existing FM-1 packages, alongside corresponding source. Four current projects await matching source: BoleTE, Crips Maz, Mo Art Feud and updated Paft Dunk. K-Tea is rebuilt from Round 4 source for the browser; C0d3-Ah includes the Co Da browser edition from its source archive. The latest C0d3-Ah device package awaits source matching. K-Tea firmware uses product FM-1_934; its Round 4 source includes that identity.

Open index.html from a local web server, or use the live catalog. Start audio with the program's activation button. Desktop Chrome is the primary checked browser. A donation or optional payment supports the work; GPL rights remain in place.

The creator reported on 18 November 2026 that all latest builds passed physical FM-1 tests. This session checks browser engines and package integrity; it did not repeat physical-device tests. Device packages are existing builds, identified in FIRMWARE-REGISTER.csv. Back up projects and samples before changing firmware. Verify compatibility with your FM-1 model and flash chip, and use the documented Felucca-family installation/recovery tools. Browser playback requires no flashing.

Code: GPL-3.0-only, with upstream and component notices retained. Dinghy/Felucca and other contributors are credited in the source packages. Upstream designburg logo files are omitted. M-VAVE has not endorsed this independent collection.
